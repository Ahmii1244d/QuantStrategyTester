Quant Strategy Tester

This repository contains a Python-based web application that runs a local HTTP server to provide the UI and APIs.

Why the GitHub Pages site is blank

GitHub Pages only serves static files (HTML/CSS/JS) and cannot run the Python backend this project needs. The original UI is generated by the Python server at runtime, so the Pages site shows an empty page.

How to run locally

Run the tester locally (requires Python 3.8+):

python tester_app.py

Then open http://127.0.0.1:5000/ in your browser.

Options

  • If you want a static landing page on GitHub Pages, keep this file in the repository root (already added).
  • If you want a hosted demo, you must deploy the Python app to a server (e.g., Heroku, Railway, Render) or convert the app to a purely static frontend that uses a hosted API.

See the repository README for more details.
